# alpha.13发布时设计：独立态度估计、历史基线和条件反应

本文保留2026-10-31 alpha.13发布时的设计和状态；其后新8人已运行，结果及alpha.14修复见[完整试验](pilot-20261031-decision.md)。下文“未运行”均指原发布时。

实现前三项优化，并将原因表达收敛到少量有依据的重点。**199项离线工程检查通过；尚无本版本的新模型效果结果。** 新协议不是把旧8人的7份原始失败修成成功，也不保证降低弃答就能提高准确性。

## 为什么拆分

alpha.11/12的Q2询问再次使用的态度及改变条件，v4却要求方向绑定一条条件性反应。情景中的“如果A则可能B”与对下一次NPS类别的估计不是同一输出。本轮将三者分开：

| 输出 | 来源与含义 | 后续处理 |
|---|---|---|
| 历史延续基线 | 脚本按明确行业的所选最近调查评分计算 | 始终单列，不算AI预测或已观测未来 |
| AI态度估计prediction | 有自己text/score前提的未校准类别估计，或null | 单独核源；不合格只撤本估计，不回填基线 |
| 条件反应reactions | 如果某条件成立，可能怎样反应 | 按自己的来源审核；撤一条不连带撤有独立依据的估计 |

旧轮7/16原始命中、6/16最终命中来自全部16位置；最终6个明确类别均命中，另10个未知。不能据6/6声称100%预测可靠，也不能为覆盖率强填答案。旧轮最近NPS延续16/16是这批稳定目标的结果，不是未来总体保证。

## 生成与来源提取

decision-bound-v5的wire有facts、summaries、hypotheses、reactions、prediction、unknowns。事实仅选F/T字段；文字组件仅选F编号，完整来源原文由脚本提取。模型不复写quote，不填相互依赖的kind/condition或direction_atom。分组确定类型，原文繁简、否定和条件不被转换。

summaries最多1条且只概括text/score；标签与次数在facts展示。hypotheses最多2条，聚焦问题相关的主要候选原因或顾虑，不把长列表覆盖当解释成功；reactions最多2条且文字明确“如果/若……可能……”。prediction为null或direction/reason/source_refs/confidence，方向只选推荐/观望/不推荐，置信low/medium；含prediction共最多6个组件。结构约束减少相互矛盾字段，但仍可能选错来源、写错内容或放错栏目，仍须语义复核。

个体记忆档位可提出有限估计；limited_attitude只允许条件反应，不强作无条件估计；facts_only与insufficient不作推断。预测的所选字段须属于明确的目标行业，至少有text或score，中性标签不能单独支撑类别。理由不能借其他组件、事实区或基线卡补前提。

心理/社会理论只帮助形成有来源、可反证的解释。没有区分证据时保留未知；不要求每人填机制卡，也不以新模拟验证心理理论。

## 脚本基线的边界

baseline.json为辅助卡；渲染器和批试审计从绑定证据重算。只取survey的合法0–10整数评分，不把verbatim再算一次参评。按同业调查时点列轨迹、评分与来源F编号；冲突时点打断确定轨迹，最近同一时点分数不唯一则基线未知，即使分数落在同一类别也不任意择一。

多行业且未明确目标时未知，不从问题关键词猜行业。卡片覆盖所选历史，不能称完整档案；不同记录不合并为一个事件。category_changes只是相邻明确时点类别差异，不证明原因。基线默认“历史类别延续”是估计假设，未校准、不是本人新回答。

模型先看轨迹与基线，偏离须提出具体可见依据及不确定性；脚本只标记是否偏离，不自动证明调整合理。prediction为空时answer.direction仍是unknown，Q2统计不以baseline.direction替它计分。沿用基线的表现也不能称AI新增价值。

## 宿主使用

按[SKILL](../SKILL.md)的interview创建私有任务，生成answer.json后执行：

```bash
python3 scripts/plan_review.py precheck --bundle /private/tmp/user-interview/evidence.json --answer /private/tmp/user-interview/answer.json --output /private/tmp/user-interview/answer.checked.json --audit-output /private/tmp/user-interview/precheck.json
python3 scripts/decision_review.py prompt --bundle /private/tmp/user-interview/evidence.json --answer /private/tmp/user-interview/answer.checked.json --output /private/tmp/user-interview/review-prompt.txt
python3 scripts/decision_review.py finalize --bundle /private/tmp/user-interview/evidence.json --answer /private/tmp/user-interview/answer.checked.json --review /private/tmp/user-interview/review.json --output /private/tmp/user-interview/answer.final.json --audit-output /private/tmp/user-interview/review-audit.json
```

中间由宿主按review-prompt填写review.json。decision-scope-v1的review_version=4，复用逐分句的premise/scope/inference及角色规则，绑定证据和原wire哈希。预测首个脚本分句必须按未来有界估计审核；理由里的历史断言仍逐句核源。未知未来不是历史前提缺失，但有界也不能豁免虚构。

预检只撤回非法原组件、保留合法原值，记录original_strict_contract_pass和原组件路径。审核每个组件全部分句都检查；语义拒绝、边界政策撤下、合约待完成分别记录。局部不完整只隔离该组件，global哈希/覆盖不符停止，不补写答案。审核状态归脚本审计，不允许生成模型预先声称review_pending。模型角色识别和语义判断仍可能漏放或误撤。

## 批试契约

以下命令只是准备入口，不会自动取得新的资料授权，也不自动排除所有旧人：

```bash
python3 scripts/validation_prep.py build --profiles-dir /absolute/path/my-profiles --input-dir /private/tmp/decision-inputs --judge-dir /private/tmp/decision-judge --comparison memory_vs_computed_baselines --response-protocol decision-bound-v5 --include-zero --max-records 24
```

新用户验证另须显式排除全部已用ID、启用fresh_holdout并事前登记抽样规则。v5拒绝标签双臂，保留旧双臂协议供复现，不静默切换。8人四题两重复为64次生成、最多16批审核；生成只见可见资料、档位和脚本基线，审核只见各组件实际所选字段，双方都不读隐藏后续答案。

套餐配置显式设response_protocol=decision-bound-v5、source_review_protocol=decision-scope-v1，schema哈希取decision_protocol.schema()；共同指令不混用v4。19个执行源必须全部按实际文件冻结，列表由validation_workflow.DECISION_EXECUTION_SOURCES给出；新三个源是attitude_baseline.py、decision_protocol.py、decision_review.py。准备、freeze、执行、导入、完整审计和来源派生都支持v5，输入baseline卡即使重做提示词哈希也会被重算核对。

无新批次授权不传真实资料；现有OAuth套餐路径，不创建API Key、不充值、0自动重试，额度/传输/护栏错误停止。当前工程测试没有调用该外部模型；新schema的真实服务可用性与剩余额度需在实际执行前核验，离线通过不保证请求会成功。

## 本地验证结果与未完成项

新增20项检查，合计199项通过：包括引用原文提取、零分/冲突时点/跨行业基线、独立撤回、局部待审、禁止基线补分、输入卡篡改拦截、19源冻结，以及完整模拟生成/导入/来源审核/回执审计。合成服务由测试替身返回，不是现有套餐或真实用户效果试验。

旧8人的64份原始回答与64份来源结果经新代码兼容回放，仍57通过/7失败，Q2仍原始7/16、最终6/16，435个旧文件哈希未变。实际alpha.12发布包生成的合成证据和旧回答仍能读取；没有把旧材料迁移后冒称新模型回答。本版合成示例的绑定哈希按新版本更新。

下一次验证应事前固定：按自然分布抽样作为主结果，单列状态变化子集；若另建变化挑战集，明确它不是总体分布、不据结果替换样本。始终比较最近NPS和固定类别基线；同时报告AI全位置命中、覆盖、条件命中及偏离基线的增益，不能用基线面板替AI补分。

Q3另评少量重点原因与后续真实原因的一致性及多余因素；匹配主题不等于解释因果。先只看来源评分并封存，再开隐藏结果。独立人工评分须实际安排并留记录，当前assistant不能充当独立真人评审。新版本样本、schema和问题发生变化，不能把跨批差异直接归因于单一算法修改。
