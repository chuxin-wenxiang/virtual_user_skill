# v2027.0.0-alpha.2

## 本次改进

- 回答绑定到具体用户、问题与证据包的校验值，正文引用与 claims 相互覆盖。
- 修复异常包类型导致报错、越界分数和来源记录未核验的问题；拒绝重复 JSON 键及非有限常量。
- 增加 `interview` 命令，一次创建证据、提示词、回答模板和运行清单；不伪造回答。
- 增加时间切分验证准备工具，生成互斥分组、同题两条件、分离隐藏材料和逐文件校验值。

- 保持 alpha.1 合法证据包读取兼容，对未绑定的旧回答给出显式警告。

35 项工程回归检查通过。模型效果对照仍未执行，验证准备数量不等于实际实验样本数或回答数。

# v2027.0.0-alpha.1

日期：2026-10-26

类型：首个可运行预览版，效果对照实验待补。

## 本版提供

- 可被宿主发现的独立 Skill：`authentic-user-v2027`，与旧版并存。
- Python 3.10+ 标准库 CLI，读取本地核心档和扩展档，不连接外部服务。
- 严格排他时间边界、行业过滤、关键词证据选择和逐条来源校验值。
- 从可见证据重算摘要，排除现有全历史摘要及 L3/L4 推断。
- 依据证据深度进行有限模拟、事实摘要或证据不足降级。
- 宿主 AI 使用的生成提示词、结构化回答协议、引用和逐字引文检查。
- 明确为合成的演示档案、协议回答、回归测试和发布文件检查。

## 验证状态

已在 Python 3.12 下通过 21 项工程回归检查、Skill 格式检查和发布文件检查；已从安装 ZIP 解压后跑通准备证据、生成提示词、检查示例回答的命令链路。

工程回归检查的范围是时间切分、原话引用、读取兼容、输入异常、降级与命令链路。它不证明模拟更接近真人，不提供模型效果提升数字。

未执行模型 A/B，不包含真人验证结论。后续补充固定模型和输入、无泄漏切分、对照回答、评分、失败案例与不确定性。计划中的样本数不能作为本版已完成实验人数。

## 后续完善

个体记忆相对标签输入的效果实验、复杂条件选人、模型服务适配、自动增量、更多档案格式，以及必要时对已验证能力做更完整的应用集成。

不把未经验证的人格与因果叙事恢复为默认事实。没有原话时不补写人格，NPS 0 分不自动剔除。
